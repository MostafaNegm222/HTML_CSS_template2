# HTML/CSS Template 2

## 1. Description

A static website template built with HTML and CSS, the second in a series of layout practice templates.

## 2. Technologies and Versions

- HTML5, CSS3 (no frameworks, no build step)

## 3. Requirements and Dependencies

- A modern web browser
- No packages to install

## 4. Installation and Run Steps

```bash
git clone https://github.com/MostafaNegm222/HTML_CSS_template2.git
cd HTML_CSS_template2
```

Open `index.html` in a browser, or serve the folder with any static server.

## 5. Environment Variables

None required.

## 6. Usage and Main Features

- Multi-section static page: `index.html` with styles under `css/`, assets under `images/`, and local fonts under `webfonts/`.
